# 🐧 موسوعة وأكاديمية لينكس العربية — Linux//AR

منصة تفاعلية متكاملة باللغة العربية لتعلم مفاهيم أنظمة لينكس، أوامر الطرفية (Terminal)، ومبادئ الأمن السيبراني بطريقة عملية قائمة على التحديات والاختبارات الممنهجة.

## 🚀 الميزات والتقنيات التقنية
- **نظام المصادقة وحماية البيانات (Auth & Security):** إدارة كاملة للمستخدمين عبر Supabase Auth مع تفعيل قوانين حماية صارمة على مستوى السطور (Row Level Security - RLS) لضمان خصوصية تقدم الطلاب.
- **تتبع الإنجازات (Progress Tracking):** ربط فوري لتقدم المستخدم محلياً مع قاعدة بيانات خادم متصلة بجدول `lesson_progress`.
- **بوابة التليجرام (Telegram Gateway):** التحقق التلقائي من هوية وعضوية الطلاب في مجتمعات الأكاديمية باستخدام خوادم وخدمات Supabase Edge Functions و Webhooks المعزولة.
- **البيئة التدريبية (Sandbox):** طرفية تعليمية تفاعلية تحاكي نظام ملفات افتراضي داخل المتصفح، ومحرر أكواد تدريبي للغتي Python و Bash.
- **الاختبارات والتصنيف المستمر:** تصحيح وحفظ نتائج الاختبارات يتم من جهة السيرفر بالكامل لضمان مصداقية النتائج ومنع التلاعب البرمي.

## 📁 الهيكل المصدري للمشروع
- `index.html`, `styles.css`, `app.js`, `config.js` : ملفات الواجهة الأمامية للموقع (Front-end).
- `commands.json` : قاعدة بيانات الأوامر التعليمية والمحاكاة (تضم 1500 أمر برمي).
- `supabase/migrations/` : ملفات تهيئة الأمان وإعداد دوال التحقق وقوانين الـ RLS وقاعدة البيانات.
- `supabase/functions/telegram-gateway/` : الشيفرة البرمجية الخاصة ببوابة التيليجرام وفحص عضوية القنوات.

## 🛠️ إرشادات إعداد قاعدة البيانات والخادم (Supabase CLI)

### 1. تطبيق السياسات الأمنية وعلاقات الجداول
قم بنسخ محتوى ملف الهجرة (`supabase/migrations/202610300001_linux_ar_auth_rls.sql`) وتشغيله داخل **SQL Editor** الخاص بـ Supabase لتهيئة الـ Trigger الخاص بملفات التعريف ودوال التحقق الأمنية للمستخدمين الجدد.

### 2. نشر وظائف الخادم (Edge Functions)
باستخدام أداة الطرفية داخل المجلد الرئيسي، قم بنشر دالة بوابة التيليجرام:
```bash
supabase login
supabase link --project-ref <PROJECT_REFERENCE_ID>
supabase functions deploy telegram-gateway --no-verify-jwt
```

### 3. تكوين متغيرات البيئة والأسرار (Secrets)
في لوحة تحكم مشروعك بـ Supabase، توجه إلى **Edge Functions ➡️ Secrets** وقم بإضافة المتغيرات الحساسة التالية:
- `TELEGRAM_BOT_TOKEN` : الرمز السري لبوت التيليجرام الخاص بك.
- `TELEGRAM_WEBHOOK_SECRET` : قيمة مشفرة عشوائية لتأمين طلبات الـ Webhook.
- `TELEGRAM_CHANNEL` : مسار معرف قناتك الرسمية المستهدفة للتحقق.

### 4. إعداد ربط Webhook بوت التيليجرام
نفذ الطلب التالي عبر Bash لربط البوت بالدالة المنشورة وتثبيت السر المشترك:
```bash
curl -sS -X POST "https://api.telegram.org/bot<YOUR_BOT_TOKEN>/setWebhook" \
  --data-urlencode "url=https://<YOUR_PROJECT_ID>.supabase.co/functions/v1/telegram-gateway" \
  --data-urlencode "secret_token=<YOUR_WEBHOOK_SECRET>"
```

## 🔒 حدود البيئة التعليمية الحالية
- الطرفية المدمجة هي محاكاة افتراضية تفاعلية آمنة داخل المتصفح (Client-side Sandbox) لضمان سلامة خوادم الاستضافة ومنع تشغيل البرمجيات الخبيثة.
- محاكي محرر اللغات (Python/Bash) يدعم تشغيل الأمثلة والدروس المعيارية المحددة في المنهج التعليمي فقط.
